# Changelog

All notable changes to `pipewire-flow` and `pipewire-flow-sys` are recorded
here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and both crates follow [Semantic Versioning](https://semver.org/) with their
own version numbers. The C release each version binds is noted per entry.

## [0.3.0] - Unreleased

First published release. Versions 0.1 and 0.2 existed only in the
repository and were never released.

Binds C API 0.13.0 (`pipewire-flow-sys` 0.3.0+pwf0.13.0, `pipewire-flow` 0.3.0).

### Added

- `pipewire-flow-sys`: raw FFI declarations generated by bindgen from the C
  headers, with a committed copy used when the `bindgen` feature is off and on
  docs.rs.
- `pipewire-flow-sys` finds the C library through pkg-config, accepting only
  0.13.x. With the `vendored` feature, or when no matching install is found,
  it builds the C sources it ships with Meson and links them statically.
- `pipewire-flow`: a safe interface with owned handles that stop and clean up
  on drop, `Result`-returning calls, and Rust closures for every C callback.
- `Stream` for audio capture, video capture and audio playback, with
  session-manager or manual routing (`Routing`), media roles, target and
  video format queries, and DMABUF video capture (`PortMemory::Dmabuf`).
- `Filter` with audio, video, signal and event ports, port hold, a period
  hint, data and event pushes, per-port DMABUF planes, and linking ports to
  nodes by name.
- `DmabufPlanes`, which reads a frame's DMABUF planes without allocating on
  the real-time thread, each plane's file descriptor a `BorrowedFd` tied to
  the callback.
- `log::set_level` and `log::set_callback` to route the C library's log.
- `Error`, covering every C error code including `InvalidState` and
  `NoSpace`, plus `Unknown` for codes from a newer library, described with
  the C library's `pwf_strerror()`.
- `C_API_VERSION`, the C API version a build was compiled against.
- Twelve examples that follow the C library's own, from audio capture to
  manual linking and DMABUF bundling.
